# il-agent-configs-data

Source of the `il-agent-configs-data-v1` Wonderful Function — the HTTP
endpoint that the `apps/il-agent-configs` Wonderful App calls to load and
mutate IL agent config data (overview, agent detail, baseline updates).

Deploy via `node functions/il-agent-configs-data/deploy-function.mjs` with
`WONDERFUL_API_KEY` set.

See `docs/superpowers/plans/2026-05-28-il-agent-configs-v1.md` for the full
plan.
